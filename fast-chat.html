What you can do

Built around practical conversation.

Ask and explore

Use natural-language prompts for everyday questions, ideas, explanations and task planning.

Work with responses

Use available response actions to copy an answer, provide feedback or request another response.

Read structured answers

Responses can include formatted text, lists, code and tables. Wide tables can be scrolled within the message area.

Use voice when supported

Voice input depends on microphone permission and a supported speech-recognition service. Read-aloud depends on an available device text-to-speech voice.

For larger supported documents and more structured tasks, use Deep Analysis rather than treating the ordinary chat field as a document-processing workflow.
